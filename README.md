# agent-teams

Easy agent teams setup for Claude Code for SDLC automation.

## Skills

This project includes a self-contained set of Claude Code skills for the full software development lifecycle:

| Skill | Purpose |
|-------|---------|
| `sagerstack-planner` | Phase planning with 4-member agent team |
| `sagerstack-builder` | Implementation with 2-member agent team |
| `sagerstack-code-qa` | Code QA validation and UAT |
| `sagerstack-code-planning` | Mandatory planning workflow before coding |
| `sagerstack-software-engineering` | Python architecture (Vertical Slice + DDD, TDD) |
| `sagerstack-local-testing` | Local environment, fixtures, Docker, LocalStack |
| `sagerstack-deploy-aws` | AWS infrastructure with Terraform |
| `project-memory` | Structured project memory tracking |
